# FR-I. 딥 리서치 에이전트 (Deep Research Agent)

## FR-I1. 메뉴 및 접근 제어

- **FR-I01** 사이드바에 "딥 리서치 에이전트" 메뉴(`/deep-research`)를 추가한다. 표시 조건은 `deep_research.read` 권한 보유 (FR-F25 참조). 접근 제어는 서버 측 `require_permission("deep_research", "read")`로 수행하고 프론트엔드는 권한 기반으로 메뉴를 렌더링한다.
- **FR-I02** "딥 리서치 에이전트" 메뉴는 **사용자 역할 이상**(사용자·프리미엄 사용자·운영자)이면 접근할 수 있다. 세 역할 모두 `deep_research.read` 권한이 시드로 부여된다. 권한이 없는 계정(예: 비활성/역할 미부여)은 403 Forbidden.

## FR-I2. 채팅 인터페이스

- **FR-I03** 페이지는 채팅창 형태의 UI로 구성된다. 사용자 메시지와 에이전트 메시지가 교대로 표시되며, 에이전트의 중간 진행 상황(플랜, 스텝 진행, 검색 중 등)과 최종 결과도 동일 채팅 흐름에 렌더링된다.

## FR-I3. 조사 워크플로우

- **FR-I04** 워크플로우는 다음 단계로 구성된다.
  1. 사용자가 조사 대상/질문을 채팅 입력으로 전송한다.
  2. 에이전트가 해당 조사 대상에 대한 **플랜**(조사 항목/스텝 목록)을 생성하여 채팅에 제시한다.
  3. 사용자는 플랜을 **편집**(항목 추가·수정·삭제)하거나 그대로 **승인** 또는 **거절**할 수 있다. 거절 시 조사를 진행하지 않는다.
  4. 승인된 플랜만이 딥 리서치 실행의 입력이 된다. 미승인 상태에서는 조사가 시작되지 않는다.
- **FR-I05** 딥 리서치 실행은 승인된 플랜을 기반으로 다수 스텝을 반복하는 **에이전트 루프**로 동작한다. 각 스텝에서 LLM은 필요 시 **웹 검색 도구**를 호출하여 외부 정보를 수집하고, 수집된 정보를 종합하여 다음 스텝을 계획한다. 중간 진행 상황과 최종 결과는 채팅 창에 **스트리밍**으로 표시된다.
  - **백그라운드 실행**: 에이전트 루프는 HTTP 연결과 무관하게 서버 프로세스 내 **백그라운드 태스크**(`asyncio.create_task`)로 실행된다. `POST /sessions/{id}/run`은 태스크 시작 후 **202 Accepted**를 즉시 반환하며, 진행 상황은 별도의 **`GET /sessions/{id}/stream`** SSE 엔드포인트로 조회한다. 클라이언트는 페이지를 닫았다가 다시 들어와도 스트림을 재개방해 진행 상황을 이어볼 수 있다(과거 이벤트 재생 + 실시간 tail). 완료된 스텝/보고서는 DB에 영속화된다.
  - **제약**: 단일 서버 프로세스 단위이며 서버 재시작 시 진행 중 태스크는 소실된다. 시작 시 복구(`main.py` lifespan)가 `running` 상태로 갇힌 세션을 `approved`로 되돌려 재실행 가능하게 한다.

## FR-I4. 모델 선택 및 LLM 백엔드

- **FR-I06** 채팅 세션 시작 시 사용자가 사용할 LLM 모델을 선택한다. 선택 단위는 **세션 단위**이며, 한 세션 동안 선택한 모델이 유지된다. 선택 가능한 모델은 모델 관리 메뉴(FR-J)에서 **활성화**된 모델만 표시된다. 활성화된 모델이 없으면 모델 선택 컨트롤이 비활성화되고 운영자에게 모델을 등록하라는 안내가 표시된다.
- **FR-I07** LLM 호출은 **Ollama Cloud** 또는 **OpenCode Zen API Key** 제공자를 통해 수행된다. 사용자가 선택한 모델이 속한 제공자의 설정(FR-J03)을 백엔드에서 사용하여 호출하며, API 키는 클라이언트에 노출되지 않는다(NFR-S11 참조).

## FR-I5. 콘텐츠 렌더링 및 UI/UX

- **FR-I08** 딥 리서치 페이지는 세션 목록 사이드바와 채팅 영역 사이의 **가로 경계를 드래그하여 크기를 조절**할 수 있는 리사이저를 제공한다. 세션 목록의 기본 너비는 기존보다 넓어야 하며(280px 기본), 최소/최대 폭 제약(200px~480px)을 둔다. 구현에 `react-resizable-panels`를 사용한다. 또한 **실행 중(`running`)인 세션도 삭제할 수 있다** — 삭제 시 백엔드가 백그라운드 태스크를 취소하고 이벤트 버퍼를 정리한 뒤 행을 삭제하며, 프론트엔드는 진행 중인 스트림 조회를 중단한다.
- **FR-I09** 에이전트가 생성하는 조사 결과(스텝 진행·최종 보고서)는 raw 텍스트가 아닌 **풍부한 렌더링**으로 표시된다.
  - **마크다운**: 제목·목록·표·인용·링크·강조 등 GFM 마크다운을 렌더링한다(`react-markdown` + `remark-gfm`).
  - **코드**: 코드 블록에 구문 강조(highlight.js/`rehype-highlight`)와 **복사 버튼**을 제공한다. 테마는 라이트/다크 모드를 모두 지원한다.
  - **Mermaid**: ` ```mermaid ` 펜스드 코드 블록을 감지해 다이어그램으로 렌더링한다(`mermaid` 동적 임포트, 다크 모드 자동 감지).
  - **draw.io**: ` ```drawio ` 펜스드 코드 블록(drawio XML)을 감지해 `viewer.diagrams.net` iframe + postMessage 프로토콜로 인터랙티브 다이어그램으로 렌더링한다. 인터넷 연결이 필요하다.
  - **스트리밍 중**: 에이전트 실행 중 SSE로 수신되는 실시간 텍스트는 raw로 표시하고, 스텝/보고서 완료 시점에 마크다운 렌더링으로 전환한다(불완전 마크다운으로 인한 레이아웃 점프 방지).
