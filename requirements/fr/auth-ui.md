# FR-C. 프론트엔드 — 인증 UI

- **FR-C01** `/login` 페이지에 이메일/비밀번호 로그인 폼이 제공된다.
- **FR-C02** 로그인 성공 시 사용자 정보를 조회해 상태에 저장하고 `/`로 이동한다.
- **FR-C03** Google OAuth 로그인 버튼이 표시되나 현재는 비활성화(TODO) 상태이다.
- **FR-C04** 미인증 접근 시 `proxy.js`가 `/login`로 리다이렉트한다. 반대로 `/login`에서 토큰이 있으면 `/`로 리다이렉트한다.
- **FR-C05** 앱 로드 시 `AuthInitializer`가 `/auth/me`를 호출해 사용자 상태를 hydrate한다(새로고침 시 세션 복원).
